# 001 扩展进程状态契约

## 修改的信息

- 为 `ProcessError` 增加 `IsRunningFailed`，区分 PID 查询错误与进程已经退出。
- 为 `ProcessManager` 增加 `is_running` 契约。PID 为零和未实现查询的管理器返回 `IsRunningFailed`，不以 `false` 代替查询错误；具体操作系统进程管理器可覆写该方法。
- 为 `NodeState::can_transition_to` 增加 `WaitingReady -> Unhealthy` 与 `Unhealthy -> Ready` 两条迁移，并为公开接口补充示例。

## 修改的文件与文件内位置

- `crates/platform/node/src/contracts.rs`：`ProcessError::IsRunningFailed`、`ProcessManager::is_running`。
- `crates/platform/node/src/state.rs`：`NodeState::can_transition_to` 的迁移表与示例。

## 检查结果

- `is_running` 契约：PID 非零时由具体实现查询状态；PID 为零或无法查询时返回 `IsRunningFailed`，错误不会被映射为进程退出。通过代码检查。
- 状态迁移：新增两条指定迁移，现有迁移保留。通过代码检查。
