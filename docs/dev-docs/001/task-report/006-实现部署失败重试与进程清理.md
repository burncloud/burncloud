# 006 实现部署失败重试与进程清理

## 修改的信息

- 在 `DeploymentService` 增加 `cleanup_failed_runtime`，仅由调用方在 `ProcessManager::start` 成功取得新进程句柄后调用。
- 清理时调用 `ProcessManager::stop`；停止失败写入 `DeploymentError.cleanup_error`，保留既定主错误分类和状态映射。
- 复用任务 005 已实现的 `publish_with_retry`，对同一个应用事件最多重试一次。

## 修改的文件与文件内位置

- `crates/platform/node/src/deployment/service.rs`：`DeploymentService::cleanup_failed_runtime`。
