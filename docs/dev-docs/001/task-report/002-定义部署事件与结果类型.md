# 002 定义部署事件与结果类型

## 修改的信息

- 定义部署阶段与事件种类，覆盖排队、替换旧运行时、计划、启动、就绪、健康检查、首次结果、后台状态变化和失败。
- 定义部署事件及 endpoint、PID、状态、主错误和清理错误字段，供应用层接收。
- 定义首次健康部署结果、可克隆部署错误、稳定错误分类与后台监控错误。
- 定义 `DeploymentEventPublisher::publish`；文档约定返回 `Err` 表示事件未被接收，可安全重试同一事件一次。

## 修改的文件与文件内位置

- `crates/platform/node/src/deployment/mod.rs`：部署契约模块文档与类型导出。
- `crates/platform/node/src/deployment/types.rs`：部署阶段、事件、结果、错误类型及事件发布 trait。

## 检查结果

- 类型字段与开发文档一致，事件包含 `model_id`、状态、endpoint、PID、主错误和清理错误。通过代码检查。
- 首次结果事件文档限定为 `Ready` 或 `Unhealthy`；发布错误文档说明事件未被接收的重试保证。通过契约检查。
- `DeploymentMonitorError` 包含模型、PID、错误分类、主错误和清理错误，可作为通道消息。通过类型检查。
