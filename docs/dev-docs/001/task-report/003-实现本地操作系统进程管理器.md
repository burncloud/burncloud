# 003 实现本地操作系统进程管理器

## 修改的信息

- 新增 `LocalProcessManager`，按给定程序和参数启动 Tokio 子进程，并登记操作系统返回的非零 PID。
- 使用子进程句柄查询存活状态；`try_wait` 查询错误返回 `IsRunningFailed`，退出的子进程从管理表移除。
- 停止时先检查退出状态；活动进程通过 Tokio kill 并等待退出后移除。未知或已移除 PID 的重复 stop 返回成功；PID 为零返回 `StopFailed`。
- 使用 Tokio `Child` 默认的 drop 行为；丢弃管理器释放句柄，不隐式终止活动子进程。
- 按授权在 `deployment/mod.rs` 注册并导出新模块实现。

## 修改的文件与文件内位置

- `crates/platform/node/src/deployment/process.rs`：`LocalProcessManager` 与 `ProcessManager` 实现。
- `crates/platform/node/src/deployment/mod.rs`：`process` 模块声明与 `LocalProcessManager` 导出。
