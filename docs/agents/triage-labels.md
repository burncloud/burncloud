# Triage Labels

规范角色与本仓库标签一一对应：

| 规范角色 | 仓库标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 维护者待评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求明确，可交给 Agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

技能提及某个规范角色时，使用本表对应的仓库标签。
以后调整命名时，修改“仓库标签”列，保持规范角色不变。
保留仓库已有的其他标签，不擅自重命名或删除。
