# 003-内部准备请求执行报告

## 修改信息

- 任务：实现 `ArtifactRequest` 内部强类型请求。
- 分支：`codex/001-artifact-preparer`。
- 实现结果：
  - `ArtifactRequest` 仅包含已通过来源校验的 `ArtifactSource` 和必填 `Digest`。
  - `ArtifactRequest` 保持 crate 内可见，不再向 crate 外重新导出。
  - `ArtifactPreparation::prepare` 的对外参数改为 `Url` 与必填 `Digest`，请求结构在准备器内部创建。
  - Node 编排层补齐 URL、摘要解析和缺失摘要失败路径。
  - Fake、测试实现及相关调用方同步迁移到新的准备端口。

## 修改文件与位置

- `crates/platform/node/src/preparation/artifact_request.rs`
  - `ArtifactRequest` 改为 `pub(crate)`。
  - `expected_digest` 改为必填 `Digest`。
  - `new`、`source`、`expected_digest` 均保持 crate 内可见，并仅返回只读引用。
  - 测试迁移到独立的 `crates/platform/node/tests/support/artifact_request.rs`。
- `crates/platform/node/src/preparation/artifact_preparer.rs`
  - `ArtifactPreparation::prepare` 改为接收 `Url` 与 `Digest`。
- `crates/platform/node/src/preparation.rs`
  - 删除 `ArtifactRequest` 的 crate 外重新导出。
- `crates/interfaces/server/src/node_orchestrator.rs`
  - 将解析后的 URL 和必填摘要传入准备端口。
  - 缺失摘要、非法 URL 和非法摘要均转为失败状态。
- `crates/platform/node/src/fake.rs`
  - Fake 准备器同步新的准备端口签名。
- `crates/platform/node/tests/*.rs`
  - 更新测试准备器和 Fake 调用方，覆盖新的 URL 与摘要参数。
