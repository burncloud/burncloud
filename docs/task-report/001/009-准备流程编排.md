# 009-准备流程编排执行报告

## 修改信息

- 任务：实现 `ArtifactPreparer::prepare` 完整下载、校验、重试与释放流程。
- 分支：`codex/001-artifact-preparer`。
- 实现结果：
  - 新增公开异步 `ArtifactPreparer::prepare(Url, Digest)`。
  - 在公开接口内部完成 `ArtifactSource` 校验和严格 `ArtifactRequest` 构造。
  - 首个活动请求创建一个 `DownloadManager`，并由活动请求共享；最后一个请求释放管理器。
  - 首次摘要一致时返回首次下载路径的 `Verified` 回执。
  - 首次摘要不一致时删除首次文件，只重试下载和校验一次。
  - 重试摘要一致时返回重试文件路径的 `Verified` 回执。
  - 重试摘要仍不一致时删除重试文件并返回空路径的 `Failed` 回执。
  - 下载、读取、删除、管理器启动和回执构造错误均返回 `ArtifactPrepareError::PrepareFailed`。
  - `ArtifactPreparation` 实现委托到具体 `ArtifactPreparer`，保持 Node 组合根的可替换端口。
  - 未加入模型选择、Runtime 选择、启动参数、进程、READY 检查或路由注册逻辑。

## 修改文件与位置
