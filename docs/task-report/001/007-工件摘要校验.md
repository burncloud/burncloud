# 007-工件摘要校验执行报告

## 修改信息

- 任务：实现下载文件的异步摘要计算与比较。
- 分支：`codex/001-artifact-preparer`。
- 实现结果：
  - 新增私有异步 `ArtifactPreparer::verify_file_digest`。
  - 使用 `tokio::fs::File` 和分块 `AsyncReadExt::read`，避免整文件同步读取。
  - 支持 `Md5`、`Sha1`、`Sha256`、`Sha384`、`Sha512` 五种既有摘要算法。
  - 使用小写十六进制文本与规范化 `Digest` 值比较。
  - 文件打开或读取失败统一返回 `ArtifactPrepareError::PrepareFailed`。
  - 校验函数不执行删除和重试。

## 修改文件与位置

- `Cargo.toml`
  - 补充工作区 `sha1` 依赖。
- `crates/platform/node/Cargo.toml`
  - 补充 `hex`、`md5`、`sha1`、`sha2` 正式依赖。
- `crates/platform/node/src/preparation/artifact_preparer.rs`
  - 新增 `verify_file_digest` 异步校验方法。
  - 新增私有 `FileDigest` 累加器，统一五种算法的分块更新和最终编码。
  - 新增独立摘要测试模块引用。
- `crates/platform/node/tests/support/artifact_preparer_digest.rs`
  - 覆盖五种摘要算法的匹配和不匹配结果。
  - 覆盖文件无法打开时的失败错误。
