# 005-下载管理器生命周期执行报告

## 修改信息

- 任务：实现 `ArtifactPreparer` 的 `DownloadManager` 生命周期管理。
- 实现结果：
  - 新增具体 `ArtifactPreparer` 结构体。
  - 将原同名准备 trait 重命名为 `ArtifactPreparation`，避免与具体准备器冲突。
  - 以 Tokio Mutex 保护管理器引用和活动请求计数。
  - 首个请求创建并保存 `Arc<DownloadManager>`。
  - 管理器创建失败时恢复计数并返回 `PrepareFailed`。
  - 最后一个请求释放时移除管理器引用。
  - 新建准备器的空闲状态增加隔离测试。
