# 004-准备回执与校验状态执行报告

## 修改信息

- 任务：实现 `PreparedArtifact` 回执及校验状态不变量。
- 实现结果：
  - `ArtifactVerificationStatus` 仅保留 `Verified` 和 `Failed`。
  - `Verified` 回执必须有非空路径，且相对路径转换为绝对路径。
  - `Failed` 回执必须使用空路径。
  - `is_verified` 仅在 `Verified` 状态返回 `true`。
  - 非法路径/状态组合返回 `io::ErrorKind::InvalidInput`。
  - 将回执测试从生产源码移至隔离集成测试。

## 修改文件与位置

- `crates/platform/node/src/preparation/artifact_verification_status.rs`
  - 删除 `NotRequired` 状态。
- `crates/platform/node/src/preparation/prepared_artifact.rs`
  - 重写 `PreparedArtifact::new`，落实路径和状态组合不变量。
  - 保留绝对路径转换、只读访问器和状态判定。
  - 更新显示逻辑和公开 API 文档示例。
  - 删除生产文件内的测试模块。
- `crates/platform/node/tests/prepared_artifact.rs`
  - 新增隔离集成测试，覆盖成功回执、失败空路径、非法组合和显示结果。
- `crates/interfaces/server/src/node_orchestrator.rs`
  - 删除对已移除 `NotRequired` 状态的过期测试说明。
