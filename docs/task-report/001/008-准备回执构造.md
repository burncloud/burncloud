# 008-准备回执构造执行报告

## 修改信息

- 任务：实现准备结果回执构造适配。
- 分支：`codex/001-artifact-preparer`。
- 实现结果：
  - 新增私有 `ArtifactPreparer::build_receipt`。
  - `verified == true` 时构造带下载路径的 `Verified` 回执。
  - `verified == false` 时强制使用空路径构造 `Failed` 回执。
  - `PreparedArtifact::new` 的构造错误统一转换为 `ArtifactPrepareError::PrepareFailed`。
  - 回执适配函数不执行下载、文件删除或重试。

## 修改文件与位置

- `crates/platform/node/src/preparation/artifact_preparer.rs`
  - 新增 `build_receipt` 私有方法。
  - 失败状态下丢弃输入路径，防止下游误用未验证文件。
  - 新增独立回执测试模块引用。
- `crates/platform/node/tests/support/artifact_preparer_receipt.rs`
  - 新增成功回执路径保留与绝对化测试。
  - 新增失败回执空路径与状态测试。
